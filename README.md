# RSM

Desenvolva a base de um SaaS chamado Social Media Hub.

Objetivo:

Centralizar toda a gestão de clientes de social media em um único sistema.

Tecnologias:

React

Next.js

TypeScript

TailwindCSS

shadcn/ui

Supabase

Supabase Auth

Supabase Storage

Crie:

• Sistema de Login

• Cadastro

• Recuperação de senha

• Sessão persistente

• Tema claro e escuro

• Sidebar recolhível

• Topbar

• Dashboard vazio

• Sistema de permissões

Tipos de usuário:

Administrador

Equipe

Cliente

Cada usuário deve possuir:

Nome

Foto

Cargo

Email

Telefone

Empresa

Criar banco de dados inicial.

Criar layout premium inspirado em:

Notion

Linear

ClickUp

Framer

Tudo deve ser extremamente moderno.

Não implemente funcionalidades ainda.

Apenas a arquitetura.
